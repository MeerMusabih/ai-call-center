Getting Started

Connect a phone number to the contact center

Twilio phone integration

1
Install ngrok and expose the local server:
ngrok http 8000
2
Copy the ngrok HTTPS URL into .env:
TWILIO_WEBHOOK_URL=https://your-ngrok-url.ngrok-free.app
3
Add your Twilio credentials to .env:
TWILIO_ACCOUNT_SID=ACxxxxx
TWILIO_AUTH_TOKEN=xxxxx
TWILIO_PHONE_NUMBER=+1234567890
4
In the Twilio Console, set your number's webhook:
Voice URL → /webhook/call/incoming (POST)
Status URL → /webhook/call/status (POST)
5
Call your Twilio number and test the full flow.
Testing without a phone line: use the Agent Console to message the virtual agent directly.
