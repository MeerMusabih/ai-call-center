Setup Guide

How to connect Twilio

Step 1: Install ngrok and expose your local server:
ngrok http 8000

Step 2: Copy the ngrok HTTPS URL and add it to .env:
TWILIO_WEBHOOK_URL=https://your-ngrok-url.ngrok-free.app

Step 3: Add your Twilio credentials to .env:
TWILIO_ACCOUNT_SID=ACxxxxx
TWILIO_AUTH_TOKEN=xxxxx
TWILIO_PHONE_NUMBER=+1234567890

Step 4: In the Twilio Console, set your phone number's webhook:
Voice URL → https://your-ngrok-url.ngrok-free.app/webhook/call/incoming (POST)
Status URL → https://your-ngrok-url.ngrok-free.app/webhook/call/status (POST)

Step 5: Call your Twilio number and test!
Test without Twilio: Use the Test Chat tab to test the AI agent with text input.
