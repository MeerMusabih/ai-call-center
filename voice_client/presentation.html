Voice AI for customer support

AI Call Center

A fully local, bilingual (English / Arabic) voice agent that answers customer questions with natural speech — from a knowledge base the business controls, with no cloud AI APIs and no per-call fees.

100% local

STT, LLM, embeddings and search run on this machine. Audio stays on-premise.

Bilingual

English and Arabic through one multilingual pipeline, chosen by the caller.

Knowledge base

65 FAQ entries you edit live from a web page — no re-deploys.

Why build this

The problem

Contact centers are expensive, slow to staff, and hard to scale across languages.

Cost

  • Human agents are expensive per minute
  • Cloud AI APIs charge per call / per token
  • Staffing for 24/7 coverage multiplies the bill

Friction

  • Long wait times and repeat-the-question IVRs
  • Support teams often don't speak the caller's language
  • Consistent answers are hard to guarantee at scale
The insight: most calls are the same recurring questions. An FAQ-driven voice agent answers those instantly, in either language, and hands off to a human only when it should.
What we built

The solution

A caller picks a language, asks a question out loud, and gets a spoken answer — routed through three layers of intelligence.

1. IVR start

"Press 1 for English, press 2 for Arabic." A natural entry flow that sets the language for the whole call.

2. Knows the answers

Finds the right FAQ entry by meaning (embeddings), not keywords — so phrasing, typos and accents work.

3. Knows its limits

Company question with no answer? Offers a human agent. Unrelated small-talk? Politely stays on-topic.

Every response is tagged with its source (faq / company / unrelated) and auditable via the API — nothing happens silently.

Why it's fast

  • Declines never invoke the LLM — instant
  • STT and embeddings offloaded to threads with bounded concurrency
  • TTS streams audio during generation, not after

Quality tuning

  • FAQ match threshold tuned to 0.33
  • Company classifier at 0.58 similarity
  • Near-miss phrasings (pricing, coupons, billing) verified across both languages

Data & privacy

Where does the data go?

Designed to keep everything on-premise by default.

Stays local

Speech-to-text, the language model, embeddings, and the knowledge search all run on this machine.

No audio is sent to cloud AI providers; there are no per-call or per-token fees.

Two optional internet calls

Text-to-speech — edge-tts uses Microsoft's free neural voices (can be swapped for a local TTS).

Phone calls — only if you connect Twilio for real numbers.

Both are configurable / replaceable in .env.

For a fully air-gapped deployment, run your own TTS — the rest of the pipeline needs no internet at all.
Ship it

Deployment & distribution

From a laptop demo to production — same code.

Linux server

One command: ./setup.sh then ./start.sh. Auto-installs Ollama, FFmpeg, Python deps and models.

Docker / Cloud Run

Dockerfile included; deploy/cloud_run.yaml template for GCP.

Windows

setup.bat / start.bat, or WSL.

Two distribution bundles

Source bundle (50 KB)

Full code + FAQ data. Recipient runs setup and downloads models (needs internet, ~10–20 min).

Full offline bundle (3 GB)

Includes whisper, embeddings and the LLM pre-loaded. Mostly offline install via install_models.sh.

What's next

Roadmap

The architecture is modular — each bullet is a slot in the existing pipeline, not a rewrite.

More languages

The multilingual embedding model extends to new languages; add entries + a TTS voice.

Human handoff

Real agent transfer with context — the classifier already detects when a handoff is appropriate.

CRM integration

Look up account details during a call for personalized answers.

Local TTS

Swap edge-tts for a fully on-prem voice to enable air-gapped deployments.

Analytics

Dashboard for question categories, resolution rate, and language mix.

Auto-fill FAQ

Learn new questions from calls and suggest entries for human review.
